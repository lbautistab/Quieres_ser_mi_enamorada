# 💗 ¿Quieres ser mi enamorada?

Una forma diferente, divertida y creativa de hacer la pregunta más importante. 💕

Este proyecto es una pequeña página web interactiva diseñada para sorprender a esa persona especial y preguntarle si quiere ser tu enamorada.

La experiencia combina animaciones, GIFs y una interacción sencilla que convierte una pregunta tradicional en un momento especial.

![xodo1](https://github.com/user-attachments/assets/b7a016e8-2c35-4ecc-ae38-2e2054784245)


## ✨ Características

- 💕 **Diseño interactivo:** una experiencia sencilla y divertida.
- 🧸 **Animaciones GIF:** personajes animados que acompañan la interacción.
- 💌 **Pregunta especial:** una invitación para convertir un momento cotidiano en algo memorable.
- 🎨 **Interfaz visual:** diseño ligero y adaptable.
- 💻 **Tecnologías web:** desarrollado con HTML, CSS y JavaScript.

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|---|---|
| HTML5 | Estructura de la página |
| CSS3 | Diseño y estilos visuales |
| JavaScript | Interactividad y comportamiento |
| GIF | Animaciones visuales |

1. Clona este repositorio:

   ```bash

   ```

2. Ingresa a la carpeta:

   ```bash
   cd nombre-del-proyecto
   ```

3. Abre `index.html` en tu navegador.

También puedes utilizar la extensión **Live Server** de Visual Studio Code para visualizar los cambios en tiempo real.
